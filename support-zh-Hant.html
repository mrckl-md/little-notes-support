使用說明與支援

免費的離線加密工具。無廣告、無 App 內購買，無需註冊伺服器帳號。

問題回報

透過 GitHub Issues 回報問題

此入口公開可見，提交需要 GitHub 帳號。請僅提供 App 與 iOS 版本、機種、操作步驟及錯誤訊息。不要提交姓名、電話、信箱、私鑰、備份密碼或私人聊天；截圖請遮蔽敏感內容。涉及私人資料的請求，請使用 App 內「設定 → 關於與說明 → 使用說明與支援」顯示的聯絡管道。

如何開始？

在主 App 建立身份和公開接收卡；在「朋友」中掃描或匯入朋友的接收卡，並核對完整指紋。不要分享私鑰或鑰匙備份。

如何在鍵盤加密？

在 App 設定中共用已核對的接收卡，再於 iOS 設定 → 一般 → 鍵盤 → 鍵盤加入小紙條。切換鍵盤、選朋友、寫信後點「加密並填入」，再自行傳送。安全輸入欄位可能改用系統鍵盤。

如何解密？

開啟 iOS 鍵盤完整取用，並在主 App 開啟 15 分鐘鑰匙授權。複製完整密文，在「讀信」主動貼上。結果留在鍵盤內，授權過期需回 App 重新開啟。

完整取用會上傳內容嗎？

App 沒有訊息伺服器或連網傳輸實作。完整取用用於本機共用等功能，但系統亦授予網路能力，不能說 iOS 已另行禁止連網。

為何沒有記錄或無法開啟訊息？

分別檢查鑰匙、傳送、接收的儲存設定與鍵盤授權；回主 App 匯入記錄。檢查接收卡、原鑰匙、完整密文及授權期限。附加密碼組合在主 App 使用。新建鑰匙不能開啟舊訊息。

如何清除？

設定中的鍵盤頁可停用或清除詞語學習，預設不學習。清除所有敏感資訊會刪除本機資料，App 內無法復原；先備份需要的鑰匙。外部副本不會同步刪除。
