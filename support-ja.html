使い方とサポート

無料のオフライン暗号化ツール。広告・アプリ内課金はなく、サーバーアカウントも不要です。

問題の報告

GitHub Issues で問い合わせる

投稿内容は公開され、投稿には GitHub アカウントが必要です。アプリ・iOSのバージョン、機種、手順、エラーのみ記載してください。氏名、電話番号、メールアドレス、秘密鍵、バックアップのパスワード、私的な会話は投稿しないでください。画像の機密部分も隠してください。個人的な情報を含む依頼は、アプリ内の「設定 → このアプリとヘルプ → ヘルプとサポート」に表示される連絡先をご利用ください。

使い始めるには？

主アプリで身份と公開受信カードを作成します。友達のカードを読み取り・読み込みし、フィンガープリント全体を照合してください。秘密鍵や鍵のバックアップは共有しません。

キーボードで暗号化するには？

アプリで照合済みカードの共有を有効にし、iOSの設定 → 一般 → キーボード → キーボードから追加します。対応する入力欄で友達を選び、文章を作成して暗号化・挿入し、送信は自分で行います。機密入力欄ではシステムキーボードに切り替わる場合があります。

復号するには？

iOSでフルアクセスを有効にし、主アプリで15分間の鍵の許可を与えます。完全な暗号文をコピーし、読むモードで自分で貼り付けます。結果はキーボード内に残ります。期限切れの際は主アプリで再度許可します。

フルアクセスで入力が送信されますか？

メッセージサーバーやネットワーク送信機能はありません。ローカル共有などに使用しますが、iOSの権限自体にはネットワーク機能も含まれます。別途通信を禁止する権限ではありません。

記録がない、または読めない場合は？

各保存設定と鍵の許可を確認し、主アプリへ戻って記録を取り込みます。宛先、元の鍵、暗号文の欠落、許可期限を確認してください。追加パスワードの組み合わせは主アプリで使います。新しい鍵では古いメッセージを開けません。

データを消去するには？

キーボード設定で任意の語句学習を停止・消去できます。初期状態では学習しません。機密情報の全消去はアプリ管理下の端末データを削除し、アプリ内では元に戻せません。必要な鍵を先にバックアップしてください。外部コピーは対象外です。
