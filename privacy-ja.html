プライバシーポリシー

無料のオフライン暗号化ツール。広告・アプリ内課金はなく、サーバーアカウントも不要です。

対象

iPhone/iPad版「小さな手紙」とキーボード拡張、0.12.6（22）に適用します。発効・最終更新日：2026年10月4日。公開の問い合わせ先はサポートページをご覧ください。個人情報を含む依頼にはアプリ内のサポート窓口をご利用ください。

端末内の情報

テキスト、ファイル、鍵、受信カードは端末内で処理します。メッセージサーバー、広告、分析SDK、追跡はありません。入力、鍵、ファイル、連絡先を開発者に自動送信しません。鍵・送信記録・受信記録の保存は個別に選べ、初期状態ではオフです。保存資料は端末内で暗号化し、保護鍵は同期しない端末専用キーチェーンに保存します。設定も端末内に保持します。

キーボードとフルアクセス

公開カードの共有と秘密鍵による復号の許可は別です。共有を許可すると、身份名と照合済みの友達の公開カードが端末内の共有領域に入ります。この公開設定は保管庫暗号化の対象外で、システムのファイル保護を使います。復号には主アプリで15分間の許可を明示的に与え、現在の鍵を専用のローカルキーチェーン群に入れます。記録は共有領域で暗号化し、保存設定に従って主アプリに取り込みます。暗号文は利用者がシステムの貼り付けボタンを押したときに読み取り、自動でクリップボードを監視しません。フルアクセスはローカル共有などに使用しますが、iOSによるネットワーク機能も含みます。本アプリは内容のアップロードに使いません。

語句学習

初期状態ではオフです。有効にするとキーボードの作成欄で確定した短い語句のみを最大500件、端末内で暗号化して保存します。無効化・消去できます。受信した平文、パスワード、他のアプリの入力は学習しません。

カメラとファイル

受信カードのQR読み取りを開いたときだけカメラを要求します。映像は端末内で処理し、保存・送信しません。連絡先、位置、マイク、モーション、広告識別子にはアクセスしません。ファイルはシステムの選択画面から利用者が指定します。画像・動画の処理は端末内で行います。出力する一時PNGは保管庫暗号化されず、該当画面を離れる、消去する、再起動する際に削除します。Apple Visionによる文字比較は端末内で行い、結果は画面のメモリ内のみです。

パスワードと削除

アプリパスワードの検証値、失敗回数、置換会話の設定は同期しないローカルキーチェーンに保存し、元のパスワードは保存しません。破壊的パスワードや有効にした失敗回数のしきい値により、元のデータ領域を消去して設定済みの置換内容を生成します。検証規則と置換設定は残る場合があります。すべての機密情報を手動で消去すると、これらも削除します。外部書き出し、受信者のコピー、システムバックアップは対象外で、記憶媒体の物理消去は保証しません。サーバーアカウントはありません。

自分で選ぶ共有

コピー、書き出し、他のアプリ経由の共有は、選択したサービスの方針に従って扱われます。本アプリにiCloud同期はありませんが、システム選択画面で指定したサービスがネットワークを使うことはあります。外部コピーを回収・削除することはできません。

サポートメールとウェブサイト

このサイトは GitHub Pages でホストしています。分析、広告、外部フォント、フォーム、追跡スクリプトは埋め込んでいません。GitHub は提供と保護のためにIPアドレス、リクエスト時刻、アクセスログを処理する場合があります。処理・保管・国際移転は下記の GitHub プライバシーステートメントをご覧ください。GitHub Issues の投稿は公開され、GitHub の方針に従い処理されます。個人情報を投稿しないでください。アプリ内の窓口へ任意に連絡された情報は対応に使用し、広告には使いません。対応に必要な期間保持し、不要になれば削除します。ただし法令上必要な場合を除きます。サイトの閲覧とアプリのオフライン処理は異なります。
