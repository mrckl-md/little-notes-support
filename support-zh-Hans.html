问题反馈

通过 GitHub Issues 反馈问题

此入口公开可见，提交需要 GitHub 账号。请仅提供 App 版本、iOS 版本、设备型号、操作步骤和错误提示。不要提交姓名、电话、邮箱、私钥、备份密码或私人聊天；截图请先遮去敏感内容。涉及私人资料的请求，请使用应用内“设置 → 关于与帮助 → 使用帮助与支持”显示的联系渠道。

如何开始？

在主 App 创建自己的身份和公开接收卡。让朋友分享接收卡，在“朋友”中扫描或导入，并核对完整指纹。公钥可以分享，私钥和钥匙备份不可分享。

如何在键盘加密？

在 App 设置中共享已核对的公开接收卡；到 iOS 设置 → 通用 → 键盘 → 键盘，添加小纸条。在允许第三方键盘的输入框中选择朋友，写信后点“加密并填入”，再自行发送。密码等安全输入框由 iOS 决定使用系统键盘。

如何在键盘解密？

在 iOS 开启键盘完全访问，并在主 App 主动授权 15 分钟解密会话。复制完整密文，切至“读信”并点系统粘贴。结果只显示在键盘面板。过期后回 App 重新授权。

完全访问是否会上传文字？

App 没有消息服务器或联网传输实现。完全访问用于本机共享和授权解密等功能，但这个系统权限同时包含网络能力；不能说 iOS 已单独禁止键盘联网。

为什么记录没有保存？

钥匙、发送记录、接收记录分别设有保存开关，默认关闭。按需开启对应选项；键盘记录还需满足本机共享与会话授权条件，再回主 App 归档。大文件不适合聊天归档，应自行导出。

打不开消息或加密按钮不可用？

确认接收卡选对、原身份钥匙仍在、密文没有被截断、解密授权没有过期。附加密码组合请在主 App 使用。不要新建一把钥匙尝试恢复旧消息。丢失原钥匙且无备份时无法恢复。

如何管理学习和删除资料？

在设置的键盘子页面管理本地词语学习；默认不学习。清除所有敏感信息会删除应用管理的本机资料，无法在 App 内撤销。请先独立备份需要保留的钥匙。外部导出不会同时删除。
