隱私權政策

免費的離線加密工具。無廣告、無 App 內購買，無需註冊伺服器帳號。

適用範圍

本政策適用於小紙條 iPhone/iPad App 及鍵盤擴充功能。生效及最近更新日期：2026-10-05；對應 App 0.12.11（27）。支援入口見本網站支援頁；涉及個人資料的請求請使用 App 內支援管道。

裝置上的資料

文字、檔案、身份鑰匙及接收卡均在裝置上處理，沒有訊息伺服器、廣告、分析 SDK 或追蹤。App 不主動將輸入、私鑰、檔案或聯絡人傳給開發者。鑰匙、傳送記錄及接收記錄可分別選擇是否儲存，預設關閉；儲存的資料在本機加密，保護金鑰使用不雲端同步的本機鑰匙圈。偏好設定儲存在本機。

鍵盤與完整取用

公開接收卡共用與私鑰復號授權分開。開啟共用後，身份名稱與已核對朋友的公鑰寫入本機共用容器；公開設定不作保險庫加密，受系統檔案保護。復號需在主 App 主動開啟 15 分鐘授權，把目前身份鑰匙放入專用本機鑰匙圈。收發記錄在共用區加密暫存，依儲存設定回主 App 歸檔。你主動點系統貼上控制項讀取密文，不自動輪詢剪貼簿。完整取用用於本機共用等功能，亦包含 iOS 授予的網路能力；本 App 與鍵盤不以此上傳內容。

詞語學習

預設不學習。開啟後僅學習在鍵盤寫信區確認的短詞組，最多 500 條，於本機加密儲存，可停用或清除。不學習收到的解密原文、密碼或其他 App 輸入。

相機、檔案和圖片

僅在開啟接收卡掃描時申請相機權限，畫面只在本機識別，不儲存或上傳。不讀取系統通訊錄、位置、麥克風、動作或廣告識別碼。檔案由你透過系統選擇器指定。圖片及影片載體處理在本機進行；輸出的臨時 PNG 未作保險庫加密，離開對應頁面、清除或重啟時移除。Apple Vision 文字識別在本機進行，結果只留在頁面記憶體。

密碼及刪除

App 密碼驗證值、錯誤計數與替代聊天預設儲存在不雲端同步的本機鑰匙圈，不儲存密碼原文。破壞性密碼或已啟用的錯誤次數門檻會清除原工作區並產生替代預設；驗證規則與預設可保留。手動清除所有敏感資訊亦會刪除這些設定。不刪除外部匯出、收件者副本或系統備份，不保證快閃記憶體的物理抹除。沒有伺服器帳號或其刪除流程。

主動分享

匯出、分享、複製或透過其他 App 傳送的內容，由所選系統服務或第三方依其政策處理。本 App 沒有 iCloud 同步，但你在系統選擇器選用的服務可能連網。我們無法收回或刪除外部副本。

支援郵件及網站

本網站由 GitHub Pages 託管。頁面不嵌入統計、廣告、外部字型、表單或追蹤程式。GitHub 為提供及保護服務，可能處理 IP 位址、請求時間與存取日誌；處理、保留及跨境傳輸詳見下方 GitHub 隱私權聲明。在 GitHub Issues 提交的內容公開可見，由 GitHub 依其政策處理，請勿填寫個人資料。若透過 App 內管道主動聯絡支援，開發者會使用你提供的資料處理請求，不用於廣告。支援資料於處理請求所需期間保留，不再需要時刪除，法律要求保留者除外。App 離線處理與網站瀏覽是不同的資料處理情境。

保護範圍與聯絡

裝置解鎖時內容可能存在記憶體或臨時檔案，無法保護已遭入侵的裝置。原鑰匙及備份遺失後，開發者無法復原訊息。隱私問題可透過 App 內支援管道提出，重大政策更動將註明日期。

隱私權利

主動提交的支援資料僅在回應請求、維護產品及履行適用義務所需範圍內處理；法律要求同意時，以同意為基礎。可透過 App 內支援管道提出適用的查閱、更正、刪除、限制處理、反對或撤回同意請求，亦可向主管機關申訴。不要在公開回報中填寫個人資料。我們不出售支援資料，不用於跨 App 廣告追蹤。App 不要求兒童提供真實姓名、生日或身分證明。

聯絡人專用方案

你建立或確認匯入的聯絡人專用方案包含演算法順序、專用金鑰與參與身份，保存在本機加密資料中。匯出方案時以指定朋友的公鑰加密，由你主動分享；開發者不接收方案。你授權鍵盤工作階段後，相關方案會隨授權寫入專用本機鑰匙圈，供鍵盤在有效期間內使用。身份鑰匙備份不包含這些方案金鑰；雙方需各自保留方案。清除本機資料不會刪除已分享給對方的副本。
