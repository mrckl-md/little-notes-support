# 小纸条 / Little Notes

Public support and privacy pages for the offline iOS/iPadOS encryption utility.

For general help, use [GitHub Issues](https://github.com/mrckl-md/little-notes-support/issues). Issues are public: never post personal details, identity keys, passwords or private conversations.

This repository contains public website assets, the project license and third-party notices. App source, signed packages, test keys and private submission materials are kept separately. The app source code has not been published in this repository.
