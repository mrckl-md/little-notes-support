隐私政策

免费的离线加密工具。无广告、无内购，无需注册服务端账号。

适用范围

本政策适用于小纸条 iPhone/iPad App 及其键盘扩展。生效及最近更新日期：2026-10-04；对应 App 0.12.6（22）。支持入口见本网站支持页；涉及个人资料的请求请使用应用内的支持渠道。

设备上的资料

文字、文件、身份钥匙和接收卡在设备上处理。没有消息服务器、广告、分析 SDK 或追踪。App 不主动把输入、私钥、文件或联系人传给开发者。身份钥匙、发送记录和接收记录可分别选择是否保存，默认关闭。保存的资料在本机加密；保护密钥使用不云同步的本机钥匙串。偏好设置保存在本机。

键盘与完全访问

公开接收卡共享和私钥解密授权分开。主动开启共享后，身份名称和已核对的朋友公钥进入本机共享容器；这些公开配置不作保险库加密，受系统文件保护。解密需在主 App 主动开启 15 分钟会话，将当前身份钥匙放入专用本机钥匙串。收发记录在共享区加密暂存，按保存设置回主 App 归档。用户主动点系统粘贴控件读取密文，不自动轮询剪贴板。完全访问用于本机共享等功能，也包含 iOS 授予的网络能力；App 和键盘不使用它上传内容。

本地词语学习

默认不学习。开启后，仅从你在键盘写信输入区确认的短词组学习，最多保存 500 条，加密存放在本机；可关闭或清除。不会学习收到的解密原文、密码或其他 App 的输入。

相机、文件和图片

只有打开接收卡扫一扫时才申请相机权限，画面在本机识别，不保存、不上传。无需系统通讯录、位置、麦克风、运动或广告标识。文件通过系统选择器由你选择；图片和视频载体处理在本机进行。处理后的 PNG 是未作保险库加密的临时文件，离开相应页面、清除或重启时移除。图片文字对照使用本机 Apple Vision OCR，结果只保留在页面内存。

应用密码与清除

应用密码的验证值、错误计数和替代聊天预设保存在不云同步的本机钥匙串，不保存密码原文。破坏性密码或启用的错误次数阈值会清除原工作区并生成替代预设；验证规则与预设可保留。手动清除所有敏感信息同时删除这些设置。清除不涉及外部导出、接收方副本或系统备份，也不保证物理擦除闪存。没有服务端账号或服务端账号删除流程。

你主动分享的内容

你导出、分享、复制或通过其他 App 发送的内容，会由你所选的系统服务或第三方按其政策处理。小纸条没有应用内 iCloud 同步，但系统选择器中由你选择的其他服务可能联网。我们无法收回或删除外部副本。

支持邮件与网站

本网站使用 GitHub Pages 托管。页面没有嵌入统计、广告、外部字体、表单或追踪脚本。GitHub 为提供及保护托管服务可能处理 IP 地址、请求时间及访问日志；处理、保留及跨境传输见下方 GitHub 隐私声明。在 GitHub Issues 提交的内容公开可见，并由 GitHub 按其政策处理，请不要发布个人资料。若你通过应用内渠道主动联系支持，开发者会使用你自行提供的信息处理请求；不用于广告。支持资料在处理请求所需期间保留，不再需要时删除，法律要求保留的除外。App 离线处理内容与浏览网站是不同的数据处理场景。

保护边界与联系

设备解锁时，内容可能存在于内存或临时文件中。加密不能保护已被攻破的设备；丢失原钥匙与备份后，开发者无法恢复消息。隐私问题可通过应用内支持渠道提出。重大政策变更将在此页注明日期。

隐私权利

对于你主动提交的支持资料，我们在回应请求、维护产品及履行适用义务所需范围内处理；法律要求同意时，以同意为基础。可通过应用内支持渠道提出适用的访问、更正、删除、限制处理、反对或撤回同意请求，也可向有管辖权的监管机构投诉。不要在公开问题反馈中填写个人资料。我们不出售支持资料，不用于跨 App 广告追踪。App 不要求儿童提供真实姓名、生日或身份证明。
